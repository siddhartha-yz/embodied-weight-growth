# Walker2d 权重手术 · 第二轮

**部分定位成功，修复未达标。** 最有希望的补丁对接近失稳的状态影响更大，但指定起姿仍然摔倒，且有六个原本可通过的近原起姿失去了稳定步态。

## Astra 改了哪里

在原版蒸馏网络上比较同为左腿支撑、右腿悬空的时刻。第三次右脚摆动接近落地时，失稳轨迹前进速度 1.67 m/s，正常同相位 0.55–0.65 m/s；同时左脚踝已向另一侧偏转。Astra 判断躯干俯仰角单独不足以区分两类状态，尝试利用已有 tanh 单元在正常状态近饱和、异常时较敏感的性质。

6Astra 通过 Codex SDK 提出两批共四个补丁。最终在开发场景选中 `r1-c1`，只改第一隐藏层同一个单元的三处参数：速度权重约 +0.20，左踝角权重约 −0.60，偏置约 +0.005。架构、输入、动力学和执行器均不变；没有重训、插入分支或加装救场控制器。未见样本在锁定候选后才执行。

## 前后对比

通过标准：走满 250 步（5 秒）且不摔，前进 ≥1 m、至少四次交替落脚。

| 测试 | 改前 | 改后 |
|---|---:|---:|
| 原起姿 0.02 rad | 5 s、2.67 m、11 步 | 5 s、2.82 m、11 步 |
| 指定失稳起姿 0.08 rad | 2.06 s 摔倒，0.76 m | 2.74 s 摔倒，1.09 m |
| 未见困难起姿 | 0/12 通过 | 3/12 通过 |
| 未见近原起姿 | 11/12 通过 | 5/12 通过 |

在未见的原始轨迹上，把**同一状态**分别送入改前和改后网络。归一化力矩变动 RMS：健康状态 **0.00266**，危险状态 **0.04013**（约 **15 倍**），困难轨迹中其余非危险状态 **0.00577**。危险标记只用于量化：左脚单支撑且速度 >1.45 m/s，或倾角在 −0.75 与 −0.30 rad 之间且速度 <−0.12 m/s。它不是控制器里的规则。正常状态也有个别力矩变化达到 0.070，且闭环回放中健康状态仍出现回归。平均影响小不能替代闭环保留测试。

- `final-results.json`：成对结果及同状态力矩比较。
- `selection.json`：开发测试的四个候选、改动、选择依据；无候选满足完整成功条件。
- `selected-weights.json`：实际部署的补丁。
- `target-traces.json` / `nominal-traces.json`：MuJoCo 实测轨迹。
