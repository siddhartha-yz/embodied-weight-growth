# Walker2d：教师辅助 BP 对照

**BP 救回了指定失稳起姿，12 个未见困难起姿也全部通过；原起姿仍走满 5 秒，但近原起姿通过率未完全保住。**

从 WSP 第二轮的同一个原始蒸馏检查点继续训练，不从零开始。代码 v8 给失稳和教师示范状态标注六路力矩；正常状态的目标是原检查点输出。损失为教师动作 MSE + λ × 正常动作 MSE + 权重改动惩罚。只更新原有连接和偏置，运行时没有教师或额外控制器。最终 BP 补丁的 1,206 个已有系数都发生了变化；WSP 实际改了 3 个。四个组的 26 个「种子、倾角」和原始模型重放结果与 WSP 第二轮逐项相同；未见测试种子没有用于训练、采样或选权重。

| 组 | 原检查点 | WSP 第二轮 | 教师辅助 BP |
|---|---:|---:|---:|
| 指定失稳起姿 | 2.06 s 摔倒 | 2.74 s 摔倒 | 5.00 s 未倒，3.13 m，11 步 |
| 原始正常起姿 | 5.00 s / 11 步 / 2.67 m | 5.00 s / 11 步 / 2.82 m | 5.00 s / 11 步 / 3.08 m |
| 未见困难起姿 | 0/12 | 3/12 | 12/12 |
| 未见近原起姿 | 11/12 | 5/12 | 8/12 |

通过判据：250 步（5 秒）不摔、前进至少 1 米且至少四次交替落脚。BP 在近原组丢失四个原本能走完的案例，同时救回一个。原起姿走完不等于原控制输出不变；正常未见原轨迹上的归一化力矩差 RMS 约为 0.0173（WSP 约为 0.00266）。

## 实际计时

- **BP，服务器单 CPU 线程**：教师标签、数据准备和采样 4.79 s；训练 14.44 s（计入全部 7,200 个更新，不只计最终候选的 200 步）；开发评估 30.13 s。到锁定共 49.38 s，锁定后的同批起姿评估 10.05 s，合计 **59.43 s**。不含脚本编写、进程启动和传输。
- **WSP 第二轮**：两次 Codex SDK 调用累计 **266.02 s**；从第一次 SDK 调用到本机收到最终结果约 **310.56 s**，含反馈、仿真、传输和编排，不含预先诊断和编写脚本。
- BP 的教师策略已经存在，本轮只计使用教师的成本。BP 多了教师动作标签，也放开了可修改参数数目；这里比较的是两条实际修复路线，不是等监督、等参数预算的算法对比。
