# 权重手术首轮 · Walker2d

结论：两处直接权重编辑没有修复指定失败，还损害原步态。

- **底模**：此前从成功控制轨迹蒸馏出的 25→24→24→6 双层网络。原模型不动；补丁保存在 `patched.json`。
- **介入**：Codex SDK 调用 6Astra 一次，只给原/失败各一条轨迹、网络系数和接口；不提供未见测试轨迹，不训练或搜索。原任务的电机、观测、动力学和回放规则不变。输出仅允许替换最多 12 个已有数字，每个绝对改变量不超过 0.30；实际改 2 个，共 1,206 个存储系数（含偏置）。
- **判据**：走满 250 步（5 秒）不摔、前进 ≥1 m、至少 4 次交替落脚。使用相同初始条件对比补丁前后；分组与起姿见 `pilot.py`。

| 场景 | 编辑前 | 编辑后 |
|---|---:|---:|
| 指定失败起姿 0.08 rad | 2.06 s 后摔倒 | 1.88 s 后摔倒 |
| 原来会走的起姿 0.02 rad | 5.00 s 未倒，2.67 m | 3.62 s 后摔倒，1.64 m |
| 未见困难起姿 | 0/12 通过 | 1/12 通过 |
| 未见近原起姿 | 10/12 通过 | 3/12 通过 |

`results.json` 保存全部成对轨迹指标；`weight-delta.json` 保存改动。两处变化均连到第二隐藏层的同一单元，约 −0.10、+0.10。固定输入为原始轨迹状态时，左髋的归一化力矩在异常时间窗口附近最多变化约 0.09，但原本正常的步态上也有同量级变化（`side-effects.json`）。因此改动虽然集中在某一时段，却没有区分正常和异常步态。

`pilot-replay.mp4` 根据指定失败起姿的实测轨迹绘制半速对照；原始帧数据在 `target-traces.json`。
