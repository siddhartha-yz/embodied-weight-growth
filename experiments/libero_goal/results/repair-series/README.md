# SmolVLA 固定权重修复：研究快照

| 阶段 | 保存的结论 | 记录 |
| --- | --- | --- |
| 酒瓶搬运：匹配抓取后再编辑 | Astra 的四权重改动使目标局第 116 步达标；同一版本继续 40 步确认酒瓶留在柜顶。该局不是从开局加载改动。 | [方法、权重和结果](weight-repair/README.md) |
| 瓶/碗改动相加 | 瓶改动能迁移到部分碗布局；相加仍没救回原酒瓶局，旧任务从 8/8 降到 5/8。 | [方法、权重和结果](multitask-repair/README.md) |
| 顺序编辑 | 第二轮修碗通过 3/3 新布局，但旧任务只保住 4/8；第三轮恢复到 7/8，却没有同时保住碗和酒瓶收益。 | [方法、权重和结果](sequential-repair/README.md) |
| 共享示范：BP 对照 WSP | BP 和 Astra 的拟合误差接近，新碗都通过 4/4；从开局都没能稳稳抬起目标酒瓶，但从相同原版抓稳状态接手时两者都能完成。 | [方法、权重和结果](bp-control/README.md) |
| 激活干预后选位置 | 自动选位置＋BP 与 Astra 定位＋BP 都通过 6/8 个新布局，各自在瓶和碗上占优；同位置直接写权重为 5/8。 | [方法、权重和结果](activation-repair/README.md) |

继续研究时，优先验证**整组改动**在独立抓取上下文里的扰动，再锁定最终盲测。当前的单特征干预能改变搬运且对个别抓取画面扰动较小，但三组组合编辑都没能从开局救回原酒瓶局。布局 14 的碗和布局 25 的瓶说明两种位置选择各有收益，不能仅用一个合计分解释。
